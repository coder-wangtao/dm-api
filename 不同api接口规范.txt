Unicode 隐写检测
检查正文里有没有看不见、却能藏信息的字符。包括零宽字符、改变文字显示方向的控制符、变体选择符。这类字符可以让一段看起来正常的文字里藏着另一段内容。

工具/命令风险检测
检查请求里有没有危险命令。例如 curl、wget、bash -c、python -c。读敏感文件再外传，或者 curl 下载脚本再交给 bash 执行，会被标成严重风险。

外联/追踪风险检测
检查有没有往外发数据或打探本机的迹象。包括查询公网 IP 的网站（如 ipify.org）、临时接收数据的地址（如 webhook.site、ngrok），以及追踪像素。普通的 http:// 链接只会记一条提示。

响应侧安全扫描
上游已经返回之后，再用同样的规则扫回复内容，并把结果记到日志。扫不到或扫超时不会拦住这次回复。

请求脱敏转发
转发到上游之前，把请求里的 API Key、Token、私钥换成打码后的值。上游看到的是打码文本，本地日志里仍保留审计记录。

严重风险强制阻断
前面任何一项标成「严重」时，这次请求直接拒绝，不会发给上游。没有打开这一项时，严重风险只记录，请求仍然转发。
